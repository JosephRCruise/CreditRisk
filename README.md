# Supplementing credit risk models
In this work, we examine the impact of external credit bureau data on credit risk models during the early months of the COVID-19 Panedmic. Our data set is taken from the Kaggle competition https://www.kaggle.com/competitions/home-credit-credit-risk-model-stability/data which uses real personal finance data from the lender Home Credit. 

Since the data set is large (~5GB), it is not included as a CSV in this repo. In order to run the included jupyter file locally, the following CSVs must be dowloaded from the Kaggle competition and saved in a local directory called data/train:

train_base.csv \\
train_static_0_0.csv \\
train_static_0_1.csv \\
train_static_cb_0.csv \\ 
train_credit_bureau_a_1_0.csv
train_credit_bureau_a_1_1.csv
train_credit_bureau_a_1_2.csv
train_credit_bureau_a_1_3.csv 
train_credit_bureau_b_1.csv
